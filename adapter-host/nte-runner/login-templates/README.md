# 已保存账号登录确认模板

来源：用户于 2026-09-08 本次维护会话提供的 2560×1440 异环登录截图，并明确授权以它做模板补齐普通登录确认。

只保留 HOTTA STUDIO 标题、登录按钮和“使用其他方式登录”按钮三个灰度区域；没有复制账号、UID、人物背景或整张私有截图。原图缩小为 1280×720 后，按 `NteSavedLogin._BOXES` 中原始坐标除以二取整裁剪，模板不经过生成式重绘。

三个区域必须在同一所属窗口中形成唯一布局, 不再要求弹窗为 16:9, 也不将独立弹窗强行拉伸到游戏画布。三个区域相关系数仍须至少 0.97。已有账号详情变化不影响这三个无账号信息区域。识别只用于这一个衔接动作, 不判断登录或每日是否成功。

## 2026-10-28 离线候选修复

- 三张源码模板与现有候选缓存逐字节一致, 不重绘或替换模板。旧匹配器将整窗缩放至 1280×720, 仅在历史整屏位置附近搜索; 独立弹窗裁边、平移和 DPI 重采样会被拒绝。
- 先在直接 owner 为官方游戏 HWND、可见且进程为 NTEGame.exe 的窗口中做模板识别, 然后要求唯一匹配窗口。Qt 版本类名不再作为身份门; 其他进程和其他 owner 仍被拒绝。最多检查 8 个所属窗口, 超出即拒绝。
- 等比例缩小识别输入至最长边不超过 1280, 保留原长宽比。以 header 为锚, 在 0.5–3.0 倍模板尺度、0.025 步长内检查两个按钮的相对布局。每尺度最多 8 个锚候选, 候选耗尽或重复布局均拒绝。按钮搜索容许 4 像素平移。
- 对输入与模板应用同一 5×5、sigma=1 高斯滤波, 比较时裁去模板外沿 3 像素, 避免裁剪外背景和缩放插值污染边缘。三模板的相关系数下限仍为 0.97; 缺失、畸形、常量模板及非有限分数拒绝。
- 点击坐标由本次匹配到的 confirm 框中心换算, 不再使用历史整屏的 y=850/1440。实际输入仍在官方锁内重新核对前台和新鲜模板输入, 每进程最多一次; 记录的是实际所属窗口像素坐标。
- 离线红测覆盖旧实现的平移、非宽屏裁剪、DPI、Qt 类名漂移、多所属窗口筛选及常量模板漏洞。绿测同时保留旧的单次点击、焦点变化、异常和诊断图失败语义。

验证命令以 ok-nte 仓库虚拟环境解释器运行本仓库的 `adapter-host/tests/validate_nte_saved_login.py` 和 `adapter-host/tests/validate_nte_saved_login_geometry.py`。测试输入由这三张非隐私模板合成, 不是当前失败弹窗的实机截图。本轮不修改安装缓存、不装机、不启动客户端或日课; 当前现场是否还存在其他布局变化, 留待自审后的正式实机验收。

`SavedLoginConfirmation` 每次工具进程最多点一次；通过官方 `operate` 持有输入锁，在官方任务线程内向所属登录弹窗发送单次鼠标点击，返回后继续官方 `ensure_main`。实际通过模板识别的输入原图单独进入本轮 artifact, 不在点击后补拍。验证、条款、付费、账号选择和凭据填写不在此模板范围。
