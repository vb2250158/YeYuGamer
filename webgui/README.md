# YeYu Gamer WebGUI

WebGUI 是编排器唯一的业务入口。它显示游戏卡片、工具参数、今日步骤、队列和当前进度。

## 今日页面

每个游戏卡片可以展开：

- 标题栏中用滑轨决定是否纳入一键每日；
- 配置游戏路径和工具路径；
- 配置该工具公开的参数；
- 为鸣潮管理同一客户端已记住账号的别名、启用状态、顺序和精确掩码标签；
- 勾选今天要做的具体步骤；
- 查看每行今天的 `completed`、`failed` 或 `skipped` 状态；
- 查看当前正在运行的游戏和步骤。

前端只编辑配置并展示 Manager 状态。它不自行推断工具是否完成，也不从风险、退出码或历史记录拼出步骤结果。

鸣潮各账号共享当前每日步骤选择和 OK-WW 参数，Run、Todo 与验收状态分别展示。已经创建执行 Run 的账号不能更换登录标签，换号应新增账号并停用旧项。标签缺失、歧义、登录、验证码或条款会暂停执行；真实多账号每日仍待实机验收。
