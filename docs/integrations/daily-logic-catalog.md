## 参数下发合同

每个后续 Adapter 必须满足以下合同，才可以把表中“待补”参数改成可编辑且可执行：

1. Manager 将已选 Todo 和经过类型校验的 profile 写入单次运行绑定；用户不能传命令、路径或原始工具配置。
2. Runner 只执行被选中的阶段；未选阶段不接触游戏。
3. 每个阶段依次回传 `started`、带同轮 artifact 的 terminal 事件；工具退出码不能单独完成 Todo。
4. 补药、购买、抽卡、PVP、分解/强化、账号设置与不可逆选择可以拥有玩法参数；实际出现消耗/确认按钮时才进入对应的人工确认边界。
5. 先在候选包中回放/验证，再由治理流程晋级到正式执行 binding。
