# 周常检查

沿用 [每日主流程](../daily-workflow.md) 的版本、日志、归因、修复与贡献步骤，单独核对周常周期。

- 读取当前 capabilities、周常定义、周期起止、账号及实际勾选范围；不能凭历史“禁用”结论停止调查。
- 追踪界面开关到 Manager 执行入口、Adapter 映射和上游任务。计划创建不代表执行；仅打开 capability 也不创造上游能力。
- 区分产品接入缺失和上游任务缺失。前者在 YeYu 正常实现与验证，后者按上游贡献流程处理，不能把 Manager 的开关称为“官方游戏逻辑”。
- 每日完成不代表周常完成；本周历史记录与本次执行分别展示，不改变周期来重置结果。
- 只执行当前授权且有官方支持的步骤；未知成本、PVP 和不可逆选择按项目人工边界处理。

历史设计线索见 `docs/integrations/weekly-todo-design.md`，其中日期、源码行号和禁用状态必须现场复核。
