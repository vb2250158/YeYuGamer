# YeYu Gamer 平台层

平台层只处理本机软件生命周期。正式入口是单个 `YeYuGamer.exe`：同一进程内启动/停止 Manager、提供 WebGUI 静态页面与本机 HTTP/SSE。诊断 CLI 只调用该宿主的 API，不是第二个后端或常驻界面。平台层不包含游戏每日逻辑，也不参与运行时队列判断。

## 使用

从已安装的软件入口启动 `YeYuGamer.exe`，它会在就绪后打开浏览器页面。关闭浏览器不会停止宿主；第二次启动只打开已有宿主的页面。当前发布不依赖独立托盘进程。游戏和自动化工具由 Manager 在用户启动队列后调用对应 Adapter 启动。

## 边界

- 不创建第二套队列、状态文件或 Manager 启动链。
- 不要求任何外部服务常驻。
- 不直接执行游戏工具的旧脚本。
- 不把启动成功误显示为每日步骤完成。
